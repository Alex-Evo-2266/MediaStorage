# Список задач

Небольшое веб-приложение для ведения списка задач. Можно добавлять, редактировать и удалять задачи, менять их статус и фильтровать список. Данные сохраняются в `localStorage` браузера.

Стек: React, TypeScript, Vite.

## Возможности

- Список задач с названием, описанием, датой создания и статусом
- Статусы: «Новая», «В работе», «Выполнена»
- Фильтр по статусу
- Проверка названия при создании и редактировании
- Подтверждение перед удалением
- Сохранение после перезагрузки страницы
- Адаптивный интерфейс для компьютера и телефона

## Запуск локально

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

После запуска откройте в браузере адрес, который покажет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

Проверить production-сборку локально:

```bash
npm run preview
```
