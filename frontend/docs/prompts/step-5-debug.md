# ДЗ4 — Шаг 5. Диагностика и исправление ошибок

## Role — Роль

Ты — Senior Frontend Developer, специализирующийся на диагностике ошибок React, TypeScript и браузерных интерфейсов.

## Task — Задача

Найди причину и исправь ошибку `[краткое описание ошибки]`.

Ожидаемое поведение: `[что должно происходить]`.

Фактическое поведение: `[что происходит сейчас]`.

## Context — Контекст

Проект Media Storage использует React, TypeScript, Vite и Material UI.

Доступные материалы:
- сообщение консоли: `[вставить текст ошибки]`;
- шаги воспроизведения: `[описать последовательность]`;
- скриншот: `[приложить изображение или указать путь]`;
- связанные файлы: `[если известны]`.

Изучи существующий код и используй все доступные диагностические данные. Если предоставлен скриншот, сопоставь визуальные дефекты с реализацией.

Не делай неподтверждённых выводов о причине ошибки.

## Format — Формат результата

1. Опиши наблюдаемый дефект.
2. Обоснуй установленную причину на основании доступных данных.
3. Внеси минимальное исправление.
4. Проверь исходный сценарий.
5. Запусти релевантные тесты и сборку, если это уместно.
6. Укажи, какие проблемы остались.

Если информации недостаточно для надёжной диагностики, запроси конкретные недостающие данные.

## Пример использования

**Ошибка:** при открытии модального окна карточки медиатеки страница перестаёт прокручиваться после закрытия окна.

**Ожидаемое поведение:** после закрытия модального окна прокрутка страницы восстанавливается.

**Проверка:** воспроизвести проблему, определить причину, исправить её и повторить сценарий открытия и закрытия.
