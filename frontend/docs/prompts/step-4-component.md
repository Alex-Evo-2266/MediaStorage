# ДЗ4 — Шаг 4. Разработка UI-компонента

## Role — Роль

Ты — Senior Frontend Developer, специализирующийся на React, TypeScript и Material UI.

## Task — Задача

Реализуй компонент `[название компонента]` для Media Storage.

Требования к компоненту:
- `[функциональное требование 1]`;
- `[функциональное требование 2]`;
- `[функциональное требование 3]`.

Реализуй базовую функциональность и необходимые состояния интерфейса.

## Context — Контекст

Изучи техническое задание, `.github/copilot-instructions.md` и существующую реализацию компонента.

Используй React, TypeScript, MUI и текущую архитектуру. Для демонстрации используй mock-данные. Backend и реальные API не подключай.

Предусмотри подходящие состояния:
- загрузка, если операция предполагает ожидание;
- ошибка при некорректных данных или неудачной операции;
- успех при успешном действии;
- пустое состояние, если нет данных.
- При создании нового компонента выделяй эго в отдельный файл
- Не пиши несколько компонентов в одном файле
- выделяй независимые функции в блок helpers

Не добавляй состояния, не имеющие смысла для данного компонента.

## Format — Формат результата

1. Изучи существующий код.
2. Внеси необходимые изменения.
3. Перечисли затронутые файлы.
4. Объясни логику и обработанные состояния.
5. Проверь сборку и релевантные тесты, если они настроены.
6. Укажи ограничения реализации.

Не переписывай несвязанные компоненты.

## Пример использования

**Компонент:** `MediaCard`.

Требования:
- показывать превью и название файла;
- отображать тип и размер;
- открывать выбранный файл по нажатию.

Критерий готовности: карточка корректно отображает типизированные mock-данные, работает с клавиатурой и соответствует тёмной теме.
