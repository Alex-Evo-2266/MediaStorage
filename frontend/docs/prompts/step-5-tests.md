# ДЗ4 — Шаг 5. Автоматизированное тестирование

## Role — Роль

Ты — frontend QA-инженер, специализирующийся на Vitest и React Testing Library.

## Task — Задача

Создай автоматизированные тесты для компонента или функции `[название]`.

Покрой позитивные сценарии и обработку ошибок. Выбирай сценарии на основе требований и реального поведения приложения.

## Context — Контекст

Проект Media Storage использует React и TypeScript.

Перед написанием тестов изучи компонент, его зависимости и существующую тестовую инфраструктуру.

Используй имеющиеся тестовые инструменты. Если их нет, определи минимальный набор зависимостей, необходимый для выполнения задания, и согласуй изменения с существующей конфигурацией.

Проверяй поведение с точки зрения пользователя. Не привязывай тесты к внутренним деталям реализации без необходимости.

## Format — Формат результата

1. Перечисли тестовые сценарии.
2. Создай тестовые файлы.
3. Запусти тесты.
4. Укажи количество пройденных и упавших тестов.
5. Опиши найденные дефекты.
6. Не скрывай упавшие тесты и не заявляй об успехе без запуска.

## Пример использования

**Задача:** протестировать фильтрацию медиатеки.

Сценарии:
- поиск отображает подходящие файлы;
- очистка запроса возвращает все файлы;
- отсутствие совпадений отображает пустое состояние.

Дополнительный сценарий: недопустимый файл не добавляется в медиатеку, а пользователю показывается сообщение об ошибке.
