# ДЗ4 — Шаг 6. Адаптивная вёрстка

## Role — Роль

Ты — frontend-разработчик, специализирующийся на адаптивных интерфейсах React и Material UI.

## Task — Задача

Проверь адаптивность страницы или компонента `[название]` и исправь обнаруженные проблемы.

## Context — Контекст

Проект Media Storage использует React, TypeScript, Vite и MUI.


Проверь интерфейс на широком экране, планшете и смартфоне. Обрати внимание на:
- боковую навигацию;
- верхнюю панель;
- сетку карточек;
- длинные названия файлов;
- диалоги и формы;
- кнопки и поля ввода.

Используй возможности MUI, CSS Flexbox, Grid и медиазапросы. Не добавляй библиотеки без необходимости.

## Format — Формат результата

1. Перечисли проблемы адаптивности.
2. Укажи условия их воспроизведения.
3. Внеси исправления.
4. Проверь сборку.
5. Сообщи результаты проверки по размерам экрана.
6. Перечисли оставшиеся ограничения.

## Пример использования

**Задача:** на мобильном экране карточки медиатеки выходят за границы страницы, а навигация занимает слишком много места.

**Критерий готовности:** сетка перестраивается, навигация остаётся доступной, содержимое не выходит за границы экрана.
