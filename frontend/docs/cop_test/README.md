# Task Manager

Простое веб-приложение для ведения списка задач на React, TypeScript и Vite.

## Возможности

- просмотр списка задач
- добавление, редактирование и удаление задач
- статусы: «Новая», «В работе», «Выполнена»
- фильтрация по статусам
- валидация обязательного названия
- подтверждение перед удалением
- сохранение задач в localStorage
- адаптивный интерфейс для компьютера и телефона

## Запуск локально

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите проект в режиме разработки:

   ```bash
   npm run dev
   ```

3. Откройте адрес, который покажет Vite, обычно это:

   ```text
   http://localhost:5173/
   ```

## Сборка

Для проверки сборки выполните:

```bash
npm run build
```

После сборки можно предварительно посмотреть результат командой:

```bash
npm run preview
```
