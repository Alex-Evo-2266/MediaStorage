
## 6. Отдельные промпты для каждого этапа

### Промпт для этапа 1: поиск, фильтрация и пустое состояние

"Проанализируй текущую реализацию медиатеки в Media Storage и заверши сценарии поиска и фильтрации в соответствии с tz.md и copilot-instructions.md. Не изменяй архитектуру проекта без необходимости. Работай только в фронтенде. Нужно сделать: единый механизм поиска по названию, фильтрацию по типам (image/video/audio), корректное пустое состояние при отсутствии совпадений, и проверить, что фильтр работает на главной странице и в отдельных разделах. После изменения выполни релевантную проверку и кратко опиши результаты."

---

### Промпт для этапа 2: просмотр файла

"Доработай функциональность просмотра медиафайла в Media Storage по требованиям tz.md. Нужно сделать полноценный сценарий просмотра: открытие выбранного файла в модальном окне, отображение превью, названия, типа и размера, переход к предыдущему и следующему файлу, закрытие кнопкой и клавишей Escape. Проверь синхронизацию с текущим отфильтрованным списком. Сохраняй текущий стиль Material UI и не добавляй лишние библиотеки. После реализации выполни проверку и сообщи, что именно было подтверждено."

---

### Промпт для этапа 3: коллекции

"Реализуй полноценную работу с коллекциями в Media Storage в соответствии с FR-03 из tz.md и правилами copilot-instructions.md. Нужно: создать коллекцию с названием, отображать список коллекций, добавлять файлы в коллекцию, удалять файлы из коллекции, удалять коллекцию с подтверждением. Все изменения должны храниться локально в React-состоянии, без серверной интеграции. Оставляй текущую архитектуру без масштабного рефакторинга. По завершении направь краткий отчёт о проверке."

---

### Промпт для этапа 4: загрузка файлов

"Заверши сценарий добавления файлов в Media Storage согласно FR-04 из tz.md. Необходимо: реализация выбора файлов через диалог, drag-and-drop, валидация допустимых типов и размера, отображение состояния загрузки/ошибки/успеха, возможность повторить операцию после ошибки, корректное освобождение временных URL. Используй существующий стек React + TypeScript + MUI, не добавляй новые библиотеки. После правки проведи проверку пользовательского сценария и опиши результаты."

---

### Промпт для этапа 5: тесты и документация

"Подготовь финальный этап реализации Media Storage: настрой Vitest + React Testing Library, напиши минимум три пользовательских теста, соответствующих tz.md, и подготовь документацию по запуску и проверке. Обязательно проверь: поиск и фильтрацию, создание коллекции и добавление файла, обработку некорректного файла с сообщением об ошибке. Обнови README и development_report с фактическими результатами тестирования и сборки. После этого выполни проверку build и тестов и укажи реальные результаты."
