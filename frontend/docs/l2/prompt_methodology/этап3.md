## 🔎 Где именно была централизована защита

Ключевая точка — MediaTagger/src/main/GaleryStore.ts, потому что:
- здесь формируется `tagIndex`
- здесь есть основное хранилище метаданных
- здесь уже обновляются теги и сохраняются данные в JSON
- это единственное место, где можно гарантировать одинаковую нормализацию для всех точек ввода

Поскольку UI-данные в MediaTagger/src/renderer/src/components/Gallery.tsx, MediaTagger/src/renderer/src/components/GalleryWithGroup.tsx, MediaTagger/src/renderer/src/components/ImageDialog.tsx, MediaTagger/src/renderer/src/components/ImageDialogWithGroup.tsx зависят от backend-слоя, централизованная защита даёт стабильный результат без широкого рефакторинга.

## 📌 Какие решения приняты

1. Нормализация в backend
   - `trim()`
   - замена множественных пробелов на один
   - `toLowerCase()`
   - это устраняет дубликаты типа `Forest`, ` forest `, `forest`

2. Сравнение на уровне normalized value
   - перед добавлением тега проверяется `normalized` против текущих значений
   - это закрывает дубли на уровне данных, а не только в UI

3. Fuzzy-подсказки
   - для коротких строк оставлен безопасный частичный поиск
   - для более длинных строк добавлен ограниченный `levenshtein`-порог
   - это позволяет показывать близкие варианты без “шумных” подсказок
