## 📌 Какие решения приняты и на чём они основаны

Основано на фактах из текущей реализации:
- в MediaTagger/src/main/GaleryStore.ts уже есть источник списка тегов: `tagIndex`, `getAllTags()`
- на уровне IPC уже есть доступ к этому набору через MediaTagger/src/preload/index.ts
- в UI раньше использовалась только проверка `!tags.includes(...)`, без подсказок и без нормализации

Поэтому логика была добавлена без изменения архитектуры:
- backend отвечает за список существующих тегов и их нормализацию
- UI отвечает только за отображение и выбор значения
