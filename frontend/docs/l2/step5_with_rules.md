## 🔎 Как работает фильтрация

В компоненте есть состояние `search`, в которое записывается текст из поля ввода. Затем список тегов вычисляется так:

- берётся исходный массив `tags`;
- применяется `filter`;
- каждый тег сравнивается с `search.trim().toLowerCase()` через `includes(...)`.

То есть:
- если пользователь вводит, например, `forest`, показываются только теги, содержащие этот фрагмент;
- если поле пустое или содержит только пробелы, `search.trim()` становится пустой строкой, а `includes("")` для любого текста возвращает `true`, поэтому отображаются все теги.

Кнопки и стиль `Chip` остались теми же, только список перед рендером ограничивается поиском.
