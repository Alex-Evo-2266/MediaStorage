Создай дизайн веб-приложения Media Storage — домашнего медиа-сервера для хранения изображений, музыки и видео. Все надписи интерфейса должны быть на русском языке.

**Стиль дизайна:** минималистичный, светлый, современный. Используй белый фон, светло-серые поверхности, тонкие границы, небольшие скругления и сдержанные синие акценты. Интерфейс должен выглядеть как готовый продукт, а не рекламный лендинг.

**Компоновка интерфейса:**

1. Слева расположи постоянное боковое меню с логотипом Media Storage и разделами:
   - Обзор
   - Изображения
   - Музыка
   - Видео
   - Коллекции
   - Настройки

2. В верхней части размести строку поиска с подсказкой «Поиск по медиатеке», кнопку уведомлений и профиль пользователя.

3. В основной области покажи заголовок «Медиатека», количество файлов и кнопку «Загрузить файлы».

4. Ниже добавь фильтры «Все файлы», «Недавно добавленные», «Избранное», а также возможность сортировки.

5. Отобрази файлы в сетке карточек. Каждая карточка должна содержать превью или миниатюру, название, тип файла и размер. Для видео дополнительно показывай длительность, для музыки — исполнителя и название композиции, если эти сведения доступны.

6. Предусмотри отдельные представления для изображений, музыки и видео. Для изображений используй галерею, для музыки — список композиций, для видео — карточки с превью.

7. Добавь удобную загрузку файлов: кнопку выбора файлов и область, в которую можно перетащить файлы. Покажи пример загрузки с индикатором прогресса.

8. В боковой панели или нижней части меню отобрази использование дискового пространства, например «Использовано 320 ГБ из 1 ТБ».

9. Предусмотри группировку файлов по коллекциям и тегам.

**Дополнительные элементы:** при выборе файла должна быть возможность открыть панель с подробной информацией: название, формат, размер, дата добавления и теги. Добавь действие «Копировать ссылку», показывающее предполагаемый способ получения файла из хранилища.

**Требования к результату:** покажи главную страницу медиатеки в окне настольного браузера. Соблюдай визуальную иерархию, не перегружай экран и используй реалистичные примеры файлов. Все основные элементы должны быть хорошо различимы.

Создай визуальную концепцию интерфейса, а не описание дизайна текстом. Если инструмент поддерживает генерацию кода, используй его только как дополнение к визуальному результату.
