Создай профессиональный UI-дизайн веб-приложения Media Storage — домашнего файлового сервера для централизованного хранения изображений, музыки и видео. Система должна предоставлять веб-интерфейс для пользователя и предусматривать API для интеграции с другими приложениями. Весь текст интерфейса должен быть на русском языке.

**Стиль дизайна:** профессиональный, функциональный, сдержанный. Используй графитовые и светло-серые поверхности, синие акценты, компактные таблицы, чёткие разделители и понятную систему иконок. Интерфейс должен напоминать современную панель управления сервером, но оставаться удобным для обычного пользователя.

**Компоновка интерфейса:**

1. Создай постоянное боковое меню с разделами:
   - Обзор
   - Все файлы
   - Изображения
   - Музыка
   - Видео
   - Группы и теги
   - Интеграции
   - Настройки

2. В верхней панели размести глобальный поиск, хлебные крошки и заметную кнопку «Загрузить файлы».

3. На главной странице покажи компактные информационные карточки:
   - Всего файлов
   - Использовано места
   - Свободное место
   - Новые файлы

4. Ниже размести таблицу медиатеки со столбцами:
   - Название
   - Тип
   - Размер
   - Дата добавления
   - Теги
   - Действия

5. Добавь фильтры по типу медиа, формату, коллекции и дате. Предусмотри переключение между табличным и карточным отображением.

6. При выборе файла открывай боковую панель с миниатюрой, метаданными, тегами, идентификатором файла и примером адреса для доступа к нему. Добавь кнопку «Копировать ссылку».

7. Предусмотри управление группами и тегами, чтобы один медиаресурс можно было находить по разным признакам без необходимости создавать несколько копий файла.

8. Добавь панель загрузки с очередью файлов, прогрессом, успешными загрузками и понятным представлением ошибок. Для неудачной загрузки покажи возможность повторить попытку.

9. Создай отдельный раздел «Интеграции». Покажи примеры подключаемых систем:
   - «Умный дом» — получение изображений для фона дашборда и доступ к музыке для автоматизированных сценариев.
   - «MediaTagger» — просмотр серверной медиатеки вместе с локальными файлами.

10. В разделе интеграций предусмотрите визуальное представление API: список доступных операций, пример адреса ресурса и кнопку просмотра документации. Не изображай интеграции как уже работающие, если это только концепция.

11. В настройках покажи параметры хранилища, организацию медиатеки и доступ к настройкам API и безопасности.

**Требования к UX:** обеспечь понятную навигацию, эффективную работу с большим количеством файлов, визуально заметные действия и ясные состояния загрузки, ошибок и пустых списков.

**Требования к результату:** покажи главный экран панели управления с таблицей файлов, статистикой и боковой навигацией. Дополнительно, если инструмент позволяет создавать несколько экранов, покажи экран загрузки, сведения о файле и раздел интеграций.

Создай визуально цельный макет реального веб-приложения. Не превращай интерфейс в лендинг или абстрактный мониторинг серверных показателей. Основное назначение приложения — хранение, организация и предоставление доступа к медиаконтенту.
